# 🚀 AI Stock Advisor Web App

An AI-powered stock analysis web application that gives BUY/SELL/HOLD signals using growth, volatility and trend analysis.

Built using Python, Flask, and modern dashboard UI.

---

## 🔥 Features

- 📈 Stock growth & volatility analysis
- 🤖 AI-based BUY / SELL / HOLD signal
- 💼 Portfolio tracker
- 💱 Multi-currency support (USD, INR, EUR, GBP)
- 🎨 Modern fintech dashboard UI
- ⚡ Real-time stock data using Yahoo Finance API

---

## 🛠 Tech Stack

- Python
- Flask
- HTML/CSS/JS
- yFinance API
- Pandas & NumPy

---

## 💻 How to Run Locally

### 1. Clone repository
git clone https://github.com/UjjwalPandey-boop/AI-stock-app.git  
cd AI-stock-app

### 2. Install requirements
pip install -r requirements.txt

### 3. Run app
python app.py

### 4. Open in browser
http://127.0.0.1:5000
