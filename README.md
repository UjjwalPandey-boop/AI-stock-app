# AI Stock App 📈

A Flask-based AI stock analysis web app with multi-currency support.

## Features
- Real-time stock data
- AI-based stock suggestions
- Portfolio tracking
- Multi-currency (USD, INR, EUR, GBP)
- Interactive charts

## How to run locally

1. Clone repo
git clone https://github.com/UjjwalPandey-boop/AI-stock-app.git

2. Go inside folder
cd AI-stock-app

3. Install dependencies
pip install -r requirements.txt

4. Run app
python app.py

5. Open browser
http://127.0.0.1:5000
